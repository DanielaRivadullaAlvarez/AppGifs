# GIFs App

Aplicación web para buscar y visualizar GIFs en tiempo real consumiendo la API de GIPHY.

Permite realizar búsquedas dinámicas, ver resultados en grid y reutilizar búsquedas previas con sistema de historial.  
Incluye cacheo de resultados para optimizar rendimiento y evitar peticiones repetidas.

Testing implementado en componentes principales usando Testing Library y Vitest.

**Cómo usar:** Escribe una palabra en el buscador o selecciona una búsqueda previa para ver los GIFs relacionados.

[Ver demo en Netlify](https://react-gifs-app-01.netlify.app/)

## Tecnologías
- React + TypeScript
- Custom Hooks
- Axios / API REST (GIPHY)
- Testing Library + Vitest
- Vite
